# 직상사 2급 실기 모바일 암기장 & 시험 모드 (198제)

직업상담사 2급 2차 실기 시험 대비 모바일 암기 및 시험 웹 애플리케이션입니다.

## ✨ 주요 기능
- **198제 기출문제 수록**: 회차별 기출문제 및 모범답안
- **모바일 최적화 UI**: 한 손 조작 네비게이션 및 반응형 카드 레이아웃
- **암기 상태 관리**: 문제별 '외움' 체크 및 '★ 북마크' 기능
- **나만의 메모 기능**: 문제별 필기 및 암기 팁 작성 (내용이 없을 때만 자동 키보드 열림)
- **⚙️ 환경설정 및 맞춤 시험**:
  - 🎯 조건별 시험 (회차별 / 북마크 / 번호 범위 지정 / 무작위 랜덤 섞기)
  - 🌓 다크 / 라이트 모드 전환
  - Aa 폰트 크기 조절 (95% ~ 130%)
  - ✏️ 문제 및 모범 답안 직접 수정 모드
  - 🔄 데이터 백업 및 기기 간 동기화 (클립보드 내보내기 / 가져오기)

Vercel을 통해 간편하게 배포할 수 있습니다 (`index.html`).
